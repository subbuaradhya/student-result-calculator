# Student Result Calculator

A simple command-line Python script to calculate a student's total marks, percentage, and pass/fail status based on 3 subjects.

## Features
- Takes input for 3 subjects (Math, Science, English).
- Calculates total marks and percentage.
- Displays if the student passed or failed.

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Run the command: `python result.py`
